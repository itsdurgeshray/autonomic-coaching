Autonomic design system

One calm system for the site and the portal

Tokens, type and components behind Autonomic Coaching and Autonomic Wellness, built so the business management portal can grow from the same parts. Every size and space is a multiple of 2px, and every line height is the font size plus 8 or plus 16.

2pxBase unit for all spacing and sizing
9Type roles: H1, H2, H3 eyebrow, page title, title, lead and three body sizes
40+Components from buttons to data tables
1Stylesheet: assets/ds.css

Calm before clever

Hairlines over boxes, generous space, one idea per block.

Clinical clarity

Plain labels, clear states, numbers set in tabular figures.

One accent per view

Green leads for Coaching, blue for Wellness. Never both as primary.

Status is never color alone

Every state carries an icon or a label with its color.
